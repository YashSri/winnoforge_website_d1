1. PROJECT OVERVIEW & ARCHITECTURE SUMMARY
================================================================================
The FORGE website is a high-performance, editorial-grade web application built
on Next.js (App Router, Turbopack), React, TypeScript, and Tailwind CSS.
The visual identity follows an Apple-inspired minimalism + Swiss Editorial
design philosophy, featuring clean 2D geometry, bespoke typography (Clash
Display, Plus Jakarta Sans, Varela Round), monochromatic & deep cobalt blue
palettes, and hardware-accelerated micro-animations without heavy 3D overhead.

Active Key Routes:
  - /                 : Homepage (Hero, Stats, Philosophy, Offerings, Voices)
  - /community        : Community Hub (Hero, Events, Gallery, Stories, Loop,
                        Engagement, Advantage, Guidelines/The Forge Code, FAQ)
  - /ecosystem        : About & Ecosystem (Who We Are, Innovation Scales, Engine)
  - /programs         : Program Catalog (Formats, Certification Tracks, Detail pages)
  - /programs/[slug]  : Dynamic certification track details (5 tracks)
  - /citadel1         : The FORGE Citadel (Hero, Structural Response, Spaces, Experience)
  - /collaborate      : Corporate & Institutional Partnership Hub
  - /mentors          : Mentors & Experts Directory
